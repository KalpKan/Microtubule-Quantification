What these numbers mean
Image
Width × height; all of these pixels are the denominator.
Otsu threshold
Green brightness (0–255) above which a pixel counts as microtubule, chosen automatically from the image's own histogram.
Microtubule pixels
Pixels above the threshold with the nucleus removed and a small clean-up, over all pixels.
Nucleus removed
Share of the picture masked out as nucleus (blue) before counting.

Is that high or low?

In the group's own experiment (single cells cropped from the same microscope, same exposure), untreated cells measured 27.9 ± 4.6 %, cells treated with nocodazole 45 µM 17.2 ± 2.6 %, and taxol-treated cells 30.7 ± 9.5 %. Those numbers only apply to pictures taken the same way: brightness, exposure, magnification and how tightly the cell is cropped all move the number, so compare images within one experiment rather than against this table.

How the number is computed

  1. Take the green channel of the image.
  2. Find the nucleus: Otsu threshold on the blue channel, then close small gaps (5 px ellipse, twice).
  3. Find microtubules: Otsu threshold on the green channel.
  4. Remove the nucleus from the microtubule mask.
  5. Clean up: open then close with a 3 px ellipse.
  6. Percentage = microtubule pixels ÷ all pixels × 100.

These are the same OpenCV steps as the Python pipeline, run by OpenCV.js in a background thread of your browser. On the three sample cells the browser result equals the Python script's result to four decimal places, and on a 60-image test set every picture matches within 0.01 point (see the accuracy table). Colour profiles embedded in PNG/JPEG files are ignored, exactly as the Python script ignores them, so Safari and Chrome give the same number.
